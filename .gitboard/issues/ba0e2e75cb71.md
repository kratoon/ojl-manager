## Description

Fairness today compares only the **total** number of shifts per employee (ADR-aaa3ccd). Compensation, PTO and substitutions can leave one employee with mostly or only night shifts while the total still looks even. Count **day shifts and night shifts separately** and balance both.

- Track worked and expected shifts per kind (day, night) for each employee, next to the total.
- Fairness (and the compensation that makes up missed shifts) should consider the gap per kind, so a night shift is preferred for someone behind on nights and a day shift for someone behind on days.
- The pair rotation stays the main model and is unchanged; this only affects choices off the rotation (compensation, substitutes, unfilled seats).
- Expected shifts per kind follow the same rules as today: workable shifts, first/last shift window, vacations with compensate on or off.

## Open questions

- How to combine the total gap and the per-kind gaps in the score (a second fairness rule with its own weight, or one rule using the worse of the two).
- Does the fairness cap (employees too far above expected are skipped) also apply per kind?
- Should the month totals and the preview show the day/night split as a warning when it is lopsided? (They already display day/night counts.)
- Window for the balance: the whole calendar range, or a rolling period so an old imbalance does not drive choices years later.

## Acceptance Criteria

- [x] Day and night shifts are counted per employee, separately from the total
- [x] Compensation and substitutes prefer the kind the employee is behind on
- [x] No employee ends up with only night (or only day) shifts when the rules allow otherwise
- [x] Rotation behaviour without compensation is unchanged
- [x] Vacations, first/last shift and compensate off are respected per kind
- [x] Result stays deterministic
- [x] ADR-aaa3ccd updated or a new ADR written for the combined score
- [x] Tests added

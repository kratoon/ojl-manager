## Context

The app needs configuration and planning data: employees, planned vacations, a shift calendar per day, etc.

- Data is sensitive and must not be publicly accessible.
- Likely one editor, many viewers once hosted on GitHub Pages.
- No paid database. GitHub Pages serves static files only, and anything fetched from Pages is publicly reachable (unless private Pages is available on the GitHub plan).

## Decision (MVP / POC only)

Read data from a **local, gitignored JSON file** (e.g. `data/local.json`). A committed sample file (e.g. `data/sample.json`) documents the shape and contains fake data only. The data model is described with a schema (zod) and accessed through a `DataStore` interface so the backend can be swapped later.

This is a POC for localhost. It is not a hosting solution: the file does not exist on GitHub Pages.

## Consequences

- Real data never enters git.
- Works on localhost only; the hosted story is covered by the separate ADR (viewer access and authentication).

## Acceptance Criteria

- [x] Decision accepted: MVP data comes from a local gitignored JSON file (localhost only, see ADR-b401965)
- [x] Hosted storage deliberately left to ADR-112163d (deferred)

Implementation details (file path, sample file, DataStore interface and schema) are tracked as stories in the OJL project when built.

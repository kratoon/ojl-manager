## Description

Pure constraint engine: rules from company, employee and date sources are normalised into constraints (ADR-86a9b67). Types: working weekdays, closed period, vacation, first shift, last shift, fixed employee for shift, forbidden employee for shift, max shifts in a row, no day/night mixing back to back, per-employee overrides.

## Acceptance Criteria

- [ ] Rule registry with zod schema per type
- [ ] Working weekdays, closed period, vacation, first/last shift
- [ ] Max shifts in a row (same kind on consecutive dates), company value 3
- [ ] No day/night mixing back to back (day+night same date, night then next-day day)
- [ ] Per-employee override of max in a row
- [ ] Per-employee override allowing exactly one day+night or night+day pair, never three mixed
- [ ] Unit tests for each rule type

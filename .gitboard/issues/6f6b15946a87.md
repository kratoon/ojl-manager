## Description

Pure constraint engine: rules from company, employee and date sources are normalised into constraints (ADR-86a9b67). Types: working weekdays, closed period, vacation, first shift, last shift, fixed employee for shift, forbidden employee for shift, max shifts in a row, no day/night mixing back to back, per-employee overrides.

## Acceptance Criteria

- [x] Rule registry with zod schema per type
- [x] Working weekdays, closed period, vacation, first/last shift
- [x] Max shifts in a row (same kind on consecutive dates), company value 3
- [x] No day/night mixing back to back (day+night same date, night then next-day day)
- [x] Per-employee override of max in a row
- [x] Per-employee override allowing exactly one day+night or night+day pair, never three mixed
- [x] Unit tests for each rule type
- [x] Rules return a verdict (0-10 with reason) or no opinion, not a boolean (see the preference scores ADR)
- [x] Violated hard rule = 0, satisfied hard rule = no opinion
- [x] Final score: any 0 wins, otherwise weighted average, neutral 5 when no opinions
- [x] Fairness implemented as a rule: score clamp(5 + gap, 1, 10), default weight 2
- [x] Fairness cap: no one more than N shifts above target while another candidate exists (default 2)
- [x] Rules combined in fixed order (by rule id) for reproducible results

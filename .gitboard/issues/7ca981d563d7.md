## Description

Deploy job in the release-please workflow, gated on release_created (ADR-ca37db3). Publish with upload-pages-artifact and deploy-pages. The site is served from a custom subdomain of ojl.cz (`manager.ojl.cz`), so it lives at the domain root and builds with the default BASE_PATH (`./`). The repo Pages source must be set to GitHub Actions.

## Custom domain

- DNS (owner of ojl.cz): `manager.ojl.cz CNAME kratoon.github.io.` No wildcard record; apex and www are untouched (already used by another site).
- Verify `ojl.cz` in the GitHub account Pages settings (TXT record) to prevent subdomain takeover.
- Set the custom domain in repo Pages settings, then enable Enforce HTTPS once the certificate is issued.
- Ship `public/CNAME` in the build (ignored by Actions deploys, but keeps the artifact self-describing).
- If the domain is ever removed, delete the DNS record too.

## Acceptance Criteria

- [x] Subdomain chosen: manager.ojl.cz
- [ ] DNS CNAME record created and `ojl.cz` verified on GitHub
- [ ] Site deploys only when a release is created
- [ ] Served on the custom domain over HTTPS
- [ ] Manual redeploy possible (workflow_dispatch)

## Description

Put `updatedAt` and `version` as the first keys of the saved JSON (ADR-112163d). Add to zod schema; warn on open if the file was written by a newer app version.

## Acceptance Criteria

- [x] Saved JSON starts with `updatedAt` then `version`
- [x] Schema accepts older files without them
- [x] Warning when file version is newer than the app

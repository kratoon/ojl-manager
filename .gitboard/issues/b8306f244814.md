## Context

Choose a package manager and Node version.

## Decision

npm with a committed `package-lock.json`, `engines.node >= 20`. Dependencies are installed with a frozen lock file (`npm ci`) in CI and builds; lock file updates are deliberate. To start, the lock file is frozen.

## Acceptance Criteria

- [x] Package manager confirmed
- [x] Frozen lock file (`npm ci`) policy confirmed
- [x] Node version pinned (>= 20)

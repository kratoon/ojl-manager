## Description

Make the `package.json` version the single source of truth (ADR-112163d) and automate it with release-please (ADR-ca37db3). Inject the version into the build, show it in the UI, release via release-please, and enforce conventional commit PR titles.

## Acceptance Criteria

- [ ] Version injected at build time and shown in the UI
- [ ] release-please workflow and config (node, starts at current version)
- [ ] PR validation fails on non-conventional PR titles
- [ ] Rules documented in CLAUDE.md (PR title format, never bump the version by hand)
- [ ] Version used in the data file header (OJL-0d42e79)

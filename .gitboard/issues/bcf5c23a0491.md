## Context

App runs on localhost now and may be hosted on GitHub Pages later (static files only).

## Decision

Develop on localhost with the Vite dev server, but build everything to be GitHub Pages ready from day one:

- Static output only: no server runtime, API routes or SSR
- Configurable base path (Vite `base`, e.g. `/ojl-manager/`) rather than hardcoded absolute URLs
- Client-side routing must work on Pages (hash routing, or a 404.html fallback)
- Deploy later via GitHub Actions; no deploy workflow needed yet

## Acceptance Criteria

- [x] Static-only constraint accepted
- [x] Base path must be configurable
- [x] Decision accepted

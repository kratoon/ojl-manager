## Description

File-based DataStore per ADR-112163d: open a JSON file from the PC (picker / drop), keep it in memory only, save as plain download named `rozvrh-smen-<DD-MM-YYYY-HHmmss>.json` (local time, e.g. `rozvrh-smen-21-11-2026-134530.json`). Works on localhost and GitHub Pages. No persistence. Warn before leaving with unsaved changes.

## Acceptance Criteria

- [x] Open file via picker and drag and drop, validated with zod, clear error on invalid file
- [x] Save downloads `rozvrh-smen-DD-MM-YYYY-HHmmss.json` in local time, zero-padded
- [x] Nothing persisted (no localStorage/IndexedDB), reload gives empty state
- [x] Unsaved-changes warning before leaving
- [x] Works on localhost and in the GitHub Pages build

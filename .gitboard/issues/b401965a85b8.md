## Context

The app handles sensitive employee data. How to host it with authentication on GitHub Pages is unresolved (ADR-112163d) and the preferred approach is not yet clear.

## Decision

The MVP runs on **localhost only**. It is **not hosted on GitHub Pages** for now. Data comes from a local gitignored file (ADR-514da88). The hosting and access decision is deferred.

## Consequences

- No viewer authentication or encryption is needed for the MVP.
- Earlier "GitHub Pages ready" decisions stay valid (static build, configurable base path), so hosting remains possible later.
- Real data must never be committed.

## Acceptance Criteria

- [x] MVP scope agreed: localhost only
- [x] Hosting and authentication decision explicitly deferred

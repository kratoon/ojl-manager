## Description

Pure generator (ADR-4a9d8da): fills shifts from a chosen start shift to the last calendar month following all rules, never touching manual assignments. Fairness: similar total shifts per employee, with per-vacation compensate flag. Unfillable shifts stay empty with a reason. Deterministic: same inputs always give the same result; a different result needs different constraints (e.g. a manual assignment).

## Acceptance Criteria

- [x] Manual assignments untouched and counted
- [x] Previous auto assignments in range recomputed
- [x] Candidates ordered by final score (fairness is part of it), then fixed tie-break
- [x] Expected/target shifts per ADR-aaa3ccd (window, counting shifts, factor k)
- [x] Compensate on: employee gets proportionally more shifts around the PTO (test)
- [x] Compensate off: targets shrink, no catch-up (test)
- [x] First/last shift shortens the window and the target (test)
- [x] Spread of shift counts bounded by the fairness cap even with strong preferences (test)
- [x] Deterministic: running twice gives equal output
- [x] Deterministic: shuffled input order gives equal output (fixed tie-break by last name, first name, id)
- [x] No randomness and no clock access inside the generator (start shift is an input)
- [x] Unit tests incl. unsatisfiable rules

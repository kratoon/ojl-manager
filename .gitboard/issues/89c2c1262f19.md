## Description

Pure generator (ADR-4a9d8da): fills shifts from a chosen start shift to the last calendar month following all rules, never touching manual assignments. Fairness: similar total shifts per employee, with per-vacation compensate flag. Unfillable shifts stay empty with a reason. Deterministic: same inputs always give the same result; a different result needs different constraints (e.g. a manual assignment).

## Acceptance Criteria

- [ ] Manual assignments untouched and counted
- [ ] Previous auto assignments in range recomputed
- [ ] Candidates ordered by final score (fairness is part of it), then fixed tie-break
- [ ] Expected/target shifts per ADR-aaa3ccd (window, counting shifts, factor k)
- [ ] Compensate on: employee gets proportionally more shifts around the PTO (test)
- [ ] Compensate off: targets shrink, no catch-up (test)
- [ ] First/last shift shortens the window and the target (test)
- [ ] Spread of shift counts bounded by the fairness cap even with strong preferences (test)
- [ ] Deterministic: running twice gives equal output
- [ ] Deterministic: shuffled input order gives equal output (fixed tie-break by last name, first name, id)
- [ ] No randomness and no clock access inside the generator (start shift is an input)
- [ ] Unit tests incl. unsatisfiable rules
